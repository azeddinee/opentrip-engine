# Contributing

Thank you for your interest in OpenTrip Engine.

## Report a bug
- Search existing issues first.
- Include WordPress and PHP versions.
- Provide clear reproduction steps and expected/actual behavior.
- Remove customer data, credentials and private information from logs or screenshots.

## Submit a pull request
1. Keep each change focused on one problem.
2. Follow WordPress PHP coding and security practices.
3. Sanitize input, escape output, verify nonces and check capabilities.
4. Do not add telemetry, tracking or external network calls without prior discussion.
5. Update documentation for user-facing changes.
6. Add tests when practical.

Test on a disposable WordPress installation before using changes on a live site. All contributions are licensed under GPL-2.0-or-later.
