# Support

OpenTrip Engine is an early-stage beta WordPress plugin for tour catalogues, departure inventory, and booking requests.

## Before asking for help

1. Check the [README](README.md) and the relevant guides in [docs/](docs/).
2. Search [existing issues](https://github.com/azeddinee/opentrip-engine/issues) for the same problem.
3. Test on a staging site with a current backup, not on a production booking system.
4. Note the OpenTrip Engine version, WordPress version, PHP version, database version, active theme, and relevant plugins.

## Bug reports

Open a [GitHub issue](https://github.com/azeddinee/opentrip-engine/issues/new/choose) with:
- A short, descriptive title.
- Exact steps to reproduce the problem.
- Expected behavior and actual behavior.
- Relevant error messages with secrets and personal data removed.
- Whether the issue also occurs with a default theme and other plugins disabled, where practical.

## Security issues

Do not report exploitable vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting when available.

## What support currently covers

Community support is provided on a best-effort basis through GitHub issues. There is no guaranteed response time, commercial support SLA, or emergency support service.

## Important beta notice

The plugin does not process payments or taxes. A booking request is not a confirmed reservation; only an administrator can confirm it, and only confirmed requests reserve departure seats. Email delivery depends on the site's WordPress mail configuration. Review the README's limitations and test your complete workflow on staging before relying on it.
